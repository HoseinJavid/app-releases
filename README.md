# اپلیکیشن مشاور ۱۱۰ — دانلود نسخه‌های رسمی

این مخزن فقط برای انتشار **فایل نصب اندروید (APK)** و گزارش نسخه‌ها است. سورس‌کد اپلیکیشن در این مخزن قرار ندارد.

## دانلود آخرین نسخه

از لینک زیر همیشه آخرین نسخهٔ منتشرشده را دریافت می‌کنید:

**https://github.com/HoseinJavid/app-releases/releases/latest/download/moshaver110-latest.apk**

یا از صفحهٔ نسخه‌ها:

**https://github.com/HoseinJavid/app-releases/releases**

## راهنمای نصب

1. فایل `moshaver110-latest.apk` را دانلود کنید.
2. اگر گوشی اجازهٔ نصب از منابع خارجی را نداد، از تنظیمات گوشی برای همین مرورگر یا فایل‌منیجر فعال کنید.
3. فایل را باز کنید و گزینهٔ «نصب» را انتخاب کنید.
4. پس از نصب، اپلیکیشن «مشاور ۱۱۰» را از صفحهٔ برنامه‌ها باز کنید.

## نسخه‌ها

هر نسخه دو فایل دارد:

- `moshaver110-latest.apk` — لینک ثابت دانلود آخرین نسخه
- `moshaver110-x.y.z.apk` — فایل مخصوص همان نسخه

گزارش کامل تغییرات هر نسخه به زبان فارسی در همان Release قرار دارد.

## نکات امنیتی

- تمام نسخه‌ها با کلید رسمی اپلیکیشن امضا شده‌اند.
- پیش از نصب، از صحیح بودن لینک دانلود مطمئن شوید.
- برای دریافت آپدیت‌ها، همیشه از همین صفحه یا لینک ثابت بالا استفاده کنید.

## پشتیبانی

برای دریافت راهنمایی، گزارش مشکل یا پیشنهاد، از بخش «پشتیبانی» داخل اپلیکیشن استفاده کنید.
